# HOW TO CREATE THE LEAD MAGNET (ACTION STEPS)

## CONTENT TO EXTRACT

Take this from /public/Yeshurun/Book/Manuscript/Yeshurun-Final-Manuscript.md:

**Include:**
1. Front matter (title page style)
2. Introduction (full)
3. Chapter 1: The Symbolism of Yeshurun (all sections 1.1 - 1.5)
4. Chapter 2 preview? Or just Chapter 1
5. "Which Path Are You On?" mini exercise
6. Back page with CTA: "Get the Full Book" + KDP link + Direct link

**Total pages:** ~12-16 pages (perfect for lead magnet)

## MOBILE-FIRST DESIGN SPECS

| Element | Spec |
|---|---|
| Size | 1080x1350px (vertical) or A4 but optimized - better 8.5" x 11" converted or vertical |
| Layout | Single column, lots of breathing room |
| Font | Inter/Lato for body (readable on mobile), Libre Baskerville for headings |
| Font Size | 11-12pt minimum, 14pt ideal for mobile reading |
| Colors | Navy (#0F1C2E), Gold (#D4B942), Cream (#F7F3E9) - match brand |
| Images | Minimal - text focused |

## TOOLS (FREE)

- **Canva** (canva.com) - Easiest, templates, mobile friendly. FREE
- **Google Docs** - Free, export as PDF
- **LibreOffice Writer** - Free
- **Capcut** - Also has PDF tools

**Recommendation:** Use Canva. Quick, looks professional.

## QUICK CREATION STEPS

1. Go to canva.com -> Create Design -> Document (8.5 × 11" or Custom)
2. Extract content from manuscript
3. Create cover: "FREE PREVIEW | Yeshurun: The Upright One | From Yaakov to Israel to Yeshurun"
4. Add content with proper headings
5. Add CTA page at end with QR code/link
6. Download as PDF (Standard)
7. Test on your phone before publishing
