QUICK START PUBLISHING GUIDE
----------------------------

For Kindle Direct Publishing (KDP) - https://kdp.amazon.com
1. Create account, go to "Create a new title" > Kindle eBook or Paperback
2. Upload manuscript (Export as .DOCX from Markdown or use direct upload)
3. Upload cover (Create 1600x2560 for Kindle or 1800x2700 for paperback, or use specs)
4. Fill in details using Book_Description.txt
5. Set pricing (eBook $2.99-$9.99, Paperback based on printing cost)
6. Publish

For Draft2Digital - https://www.draft2digital.com (wider distribution)
1. Upload manuscript and cover
2. Fill metadata from package
3. Distribute to Apple Books, Kobo, Barnes & Noble, etc.

For IngramSpark - https://www.ingramspark.com (bookstores/libraries)
1. Better for wide bookstore distribution
2. Requires ISBN (buy from Bowker or use free with some platforms)

FORMATTING TOOLS (Recommended)
------------------------------
- Atticus.io - All-in-one, great for beginners ($147 one-time or subscription)
- Vellum (Mac only) - Beautiful, industry standard for fiction/non-fiction ($199-$249)
- Scrivener - Powerful but steeper learning curve ($59)
- Google Docs/Microsoft Word - Free, works fine with KDP
- Canva - For cover design if using AI/image tools

AI TOOLS FOR COVER CREATION
---------------------------
- Ideogram/Bing/DALL-E/Midjourney - Generate cover from prompt in Cover_Specs.txt
- Canva AI Image - Easy integrated design
- Ideogram 2/3 excels at text in images (important for Hebrew/title)

NEXT STEPS
----------
1. Add author name/bio throughout
2. Generate cover using AI prompt or designer
3. Format interior for 6" x 9" trim
4. Get ISBN if selling wide (not strictly required on KDP for ebooks)
5. Proofread one final time
6. Publish as ebook first (easier), then paperback
7. Market via social media, SEO-optimized descriptions

ESTIMATED TIMELINE TO PUBLISH
-----------------------------
- Cover: 1-2 hours (AI) or 1-2 days (designer)
- Formatting: 2-4 hours with Atticus/Vellum
- Upload & review: 30 minutes
- KDP review: 24-72 hours typically

- Paperback: $9.99 - $14.99 (depends on page count ~150 pages)
